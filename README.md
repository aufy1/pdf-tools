# PDF Tool - Translator & Converter

A lightweight application designed to translate PDF documents and convert them into editable DOCX files.

## 🚀 Features

- **PDF to DOCX Conversion:** Convert read-only PDFs into editable Word documents.
- **Translation:** Translate document text while attempting to preserve original formatting.
- **Dockerized:** Fully containerized setup for easy development and deployment.

## 🛠️ Prerequisites

- [Docker](https://www.docker.com/get-started)
- [Node.js](https://nodejs.org/)
- [Vite](https://vite.dev/guide/)

### Development mode

```bash
npm run dev
```

### Production mode

```bash
npm run prod
```

### Stop

```bash
docker compose down -v
```
